# DevStack: Learn to Code in Your Browser

A simple place to learn programming with short lessons and a code editor that runs right in the page.

DevStack is for people teaching themselves to code. You can read a short lesson and try the code at the same time, without installing anything.

## Who It Is For

* People learning their first language
* Students who want extra practice
* Self taught learners who want short, clear examples
* Anyone who wants to review the basics of Python, JavaScript, TypeScript, Java, or CSS

## What You Can Do

* Pick a language and follow lessons in order
* Read a short intro, see a worked example, then try a small task
* Type code in the editor and press Run Code to see what happens right away
* Use search to find a lesson by name
* Track your progress as you finish lessons and move to the next one
* Look up common commands in the quick reference table in each lesson

You do not need to set anything up.

## How To Use It

1. Open the app.
2. Choose your language at the top. Python is selected when you first arrive.
3. Pick a lesson on the left. Start with Lesson 1 if you are new.
4. Read the lesson in the middle of the screen.
5. Type in the editor on the right, then press Run Code.
6. Read the output in the box below the editor. If something is wrong, change your code and run it again.
7. Press Next to go to the next lesson when you are ready.

Tips:

* Start with small changes to the example code before writing from scratch.
* If your code shows no output, check that you included a print or log line.
* Use Reset if you want to start the lesson code over.
* You can clear the output box at any time to keep things tidy.
